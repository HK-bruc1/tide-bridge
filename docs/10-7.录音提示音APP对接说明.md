# 10-7. 录音提示音 APP 对接说明

> 更新：2026-10-23。设备端已实现，等待 APP 对接。设备端设计见 [10-6](10-6.录音提示音APP控制方案.md)。

## 1. 功能

APP 设置页新增一个开关「录音提示音」：

- **开启（默认）**：录音开始、结束时播放提示音。
- **关闭**：不播放开始、结束提示音，录音开始更快。

开关对设备上所有正常录音都生效：APP 录音、会议录音、灵感录音，在线和离线都一样。APP 不需要区分录音类型，也不需要在每次录音前下发。

设置保存在设备上，断开 APP、换 APP 或设备重启后都保持不变。整机恢复出厂后恢复为开启。

## 2. 指令

复用现有 RDX `custom` 指令通道：

```text
查询：*APP#custom#rectone#get,<id>#
设置：*APP#custom#rectone#set,<id>,<enable>#
应答：*DEV#custom#rectone#<id>,<result>,<current>#
```

| 字段 | 说明 |
| --- | --- |
| `id` | 请求编号，1～65535 的十进制数字（最多 5 位）。设备在应答中原样带回 |
| `enable` | `1` 开启，`0` 关闭 |
| `result` | 结果：`ok` / `busy` / `arg` / `vmerr` |
| `current` | 设备当前生效值：`1` 开启，`0` 关闭 |

指令必须完全按上面的格式发送：全部小写，不带空格，不带多余字段。`id` 缺失或不合法时设备不回复。请求最长 32 字节，按现有 RDX 指令的方式写入即可，不加换行或结束符。

## 3. 应答处理

| result | 含义 | APP 处理 |
| --- | --- | --- |
| `ok` | 查询成功，或设置已保存成功 | 按 `current` 显示开关；设置时提示已保存 |
| `busy` | 设备正在录音或处于其他忙碌状态，本次未修改 | 提示「录音中，请稍后再试」，开关恢复为 `current`；不自动重试 |
| `arg` | 指令格式错误，本次未修改 | 属于 APP 实现问题，开发阶段排查 |
| `vmerr` | 设备保存失败，本次未修改 | 提示「保存失败」，开关恢复为 `current`，用户可再试 |

每条应答都带 `current`，APP 收到任何应答后都应按 `current` 刷新开关显示。

## 4. 对接流程

### 4.1 连接后查询

RDX 连接建立并订阅通知后，发送一次 `get`，按应答显示开关。

- 不轮询，录音前也不需要再查。
- 断开重连后重新查询一次。
- APP 可以缓存显示，但以设备应答为准，不要用本地缓存覆盖设备设置。

### 4.2 用户修改

1. 用户切换开关后，发送 `set`，带上目标值（不是切换指令）。
2. 等待应答期间，开关显示为处理中，不接受再次操作。
3. 收到 `id` 匹配的 `ok` 后显示已保存；其他结果按第 3 节处理。

### 4.3 请求编号与超时

- 同一时间只发一个请求，等应答或超时后再发下一个。
- `id` 在一次连接内递增，只处理与当前请求 `id` 匹配的应答，其他应答忽略。
- 建议超时 2 秒。设置超时后显示「未确认」，再用新的 `id` 发一次 `get`，按结果刷新显示。

### 4.4 兼容旧固件

旧固件不认识这条指令，不会回复。连接后的 `get` 超时，就视为该设备不支持此功能，隐藏开关，不要显示为「关闭」。

### 4.5 分包

应答最长 34 字节。BLE MTU 较小时（默认 20 字节载荷），一条应答会分成多条通知连续发送。

APP 按以下规则拼帧：

- 从 `*DEV#custom#rectone#` 开始拼接，收到其后的第一个 `#` 即为一帧结束，再按逗号拆分三个字段。
- 未拼完时又收到新的 `*DEV#` 开头，丢弃之前的半帧。
- MTU 足够大时，一条通知就是完整一帧。

## 5. 示例

```text
连接后查询，当前开启：
APP -> *APP#custom#rectone#get,1#
DEV -> *DEV#custom#rectone#1,ok,1#

用户关闭：
APP -> *APP#custom#rectone#set,2,0#
DEV -> *DEV#custom#rectone#2,ok,0#

录音中尝试开启，被拒绝，当前仍为关闭：
APP -> *APP#custom#rectone#set,3,1#
DEV -> *DEV#custom#rectone#3,busy,0#

保存失败，当前仍为关闭：
APP -> *APP#custom#rectone#set,4,1#
DEV -> *DEV#custom#rectone#4,vmerr,0#
```

## 6. 联调检查

- 新设备或恢复出厂后，查询结果为开启。
- 关闭后录音没有开始/结束提示音；重新开启后恢复。
- 断开重连、设备重启后，查询结果与上次设置一致。
- 录音中设置返回 `busy`，开关显示恢复原值；录音中查询正常。
- 默认 MTU 下应答能完整解析。
- 连接旧固件时开关被隐藏。
