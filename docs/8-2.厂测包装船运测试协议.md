# T2620 厂测包装船运测试协议

> 更新日期：2026-09-18
>
> 状态：已补齐固件业务解绑、关键 VM 回读及格式化成功后收尾；主机验证记录见第 7 节，仍需实机验收。
>
> USB CDC 接入设计另见 [8-1.产测USB_CDC接入BLE产测流程](8-1.产测USB_CDC接入BLE产测流程.md)。本文描述现有 BLE 指令，不表示 CDC 阶段 3 已实施。

## 1. 用途与边界

包装结束用于产品打包前收尾：格式化存储中的测试文件、恢复指定用户参数、清除设备端 RDX 业务绑定、禁止按键进入 DUT，完成后红灯常亮，提示测试人员拨码关机。

这不是全 VM 擦除，不清除设备身份或授权信息，也不等于解除 APP 云端账号关系。“船运模式”沿用现有日志名称，本指令不再自动关机，由测试人员拨码关机，不据此承诺硬件电池隔离或特定船运电流。

## 2. BLE 指令

通过现有 RDX 自定义命令通道发送。工厂 APP 应先连接设备并进入 DUT。

| 动作 | 请求示例 | 行为 |
|---|---|---|
| 进入 DUT | `*APP#custom#ft_dut#1#` | 请求进入 DUT，已进入则跳过重复切换 |
| 退出 DUT | `*APP#custom#ft_dut#0#` | 请求退出 DUT |
| 包装结束 | `*APP#custom#ft_finalpack_end#1#` | 执行第 3 节流程 |
| 仅关机 | `*APP#custom#ft_poweroff#1#` | 退出测试并请求关机，不执行包装清理 |
| 启用按键 DUT | `*APP#custom#ft_key_dut_enable#1#` | 写入并回读校验启用标记，再更新内存 |
| 禁用按键 DUT | `*APP#custom#ft_key_dut_disabled#1#` | 写入并回读校验禁用标记，再更新内存 |

除 `ft_dut` 外，这些命令在未进入 DUT 时被忽略。包装进行中，BLE 厂测命令、已排队的其他厂测命令和 DUT 测试按键被拦截，DUT 退出也被阻止，避免重复格式化、提前退出或改写入口标记。

包装结束、仅关机、启用/禁用入口仍按命令名称触发，不以参数值决定是否执行；不要把参数 `0` 当作取消。

这些命令仍沿用旧协议的提前回报：调用 `rdx_protocol_custom_msg_indicate(命令名, "0")` 后才投递异步任务。该回包不是动作完成证明，也不能证明任务投递、格式化或持久化成功。本次不新增 APP 完成握手或错误码协议。

## 3. 包装结束流程

### 3.1 准入检查

`rdx_dut_finalpack_end()` 在以下情况拒绝执行，不开始格式化：

- 已有包装流程在进行，或当前不在 DUT。
- 当前有其他 DUT 测试功能运行。
- OTA、录音开始/恢复、RDX 文件发送或其他格式化进行中。
- 已请求关机，或存储生命周期处于业务阻塞/延迟关机状态。

工厂 APP 应先停止测试及传输，再发送包装指令。

### 3.2 成功路径

1. 设置包装 pending 和等待格式化回调标记。
2. 调用 `rdx_uxfile_device_sd_format()`。
3. 格式化回调仅接受当前等待中的一次结果，通过任务队列交给 `app_core` 收尾；重复回调被忽略。
4. 只有 `result == MEM_FORMAT_RESULT_OK`（当前值为 `0x01`）才继续。
5. 调用 `rdx_vm_reset_defaults_no_poweroff()` 恢复指定默认参数。该接口不安排原有的约 1 秒关机定时器；若忙条件使恢复被拒绝，则中止收尾。
6. 调用 `rdx_vm_set_bound_status(0, 0)`：写入并回读业务绑定 VM，确认后更新内存绑定状态、绑定令牌，并撤销原绑定的录音授权。
7. 向 `VM_RDX_KEY_DUT_DISABLED` 写入 `0xAA` 并回读校验，成功后设置内存按键禁用状态。
8. 打印 `Finalpack committed: bound=0, key DUT disabled (verified)`。
9. 禁用自动关机，设置包装完成专用灯效：红灯持续常亮，无超时。
10. 打印 `Finalpack complete: solid red LED; turn DIP switch OFF to power off`，提示“包装测试完成，请拨码开关关机”。不主动断开 BLE，也不安排自动关机。

包装执行中、等待格式化回调及失败返工时，保持 DUT 黄灯闪烁（原 DUT 灯效）；蓝牙及充电事件不切换成普通业务灯效。只有以上清理与关键 VM 校验全部成功后，才显示完成红灯。

pending 保持到测试人员拨码关机，阻止后续厂测命令和测试按键改动完成状态。包装执行中及成功后允许 `ft_dut#0` / `ft_dut#1` 原样回包，兼容工厂 APP 收尾握手；此时不实际切换 DUT 状态或重开测试，退出由拨码关机完成。该回包仅确认收到模式请求，不代表包装通过；完成仍以红灯及提交日志为准。失败解除 pending 后恢复普通 DUT 命令处理。蓝牙、充电及普通业务灯效不能覆盖完成红灯；拨码关机及系统必要的低电关机仍可执行。完成灯效不持久化，下次启动按正常业务显示。

包装流程已移除延时断连/关机函数。仅 DUT（包括包装执行、失败及完成等待拨码关机）期间禁止空闲自动关机；统一计时入口会取消计时，避免恢复默认参数或其他事件重新开启。正常模式保留旧 VM 时间、APP 自动关机时间读写及原有计时条件，退出 DUT 后按原逻辑恢复。正常 APP 恢复出厂设置仍通过原有延时复位路径重启；只有包装调用无复位副作用的恢复接口。拨码关机、低电保护和明确关机指令仍使用既有关机收尾。

### 3.3 默认参数范围

恢复接口当前处理：

- 删除蓝牙远端信息，重置 HOGP 持久化订阅。
- 恢复经典蓝牙名称与 BLE 名称。
- 清除录音错误重启标记。
- 自动关机时间恢复默认值，但 DUT 期间不启动计时；麦克风增益恢复默认。
- 按编译条件处理 TWS 配对、AI 模式信息。
- 软件 RTC 路径保存时间戳，不清空时钟。

业务绑定由第 3.2 节单独清理。未列出的持久化项目（例如在线键位）不属于本文已确认恢复范围。

## 4. 失败处理与现有限制

| 情况 | 当前处理 |
|---|---|
| 格式化回调结果非成功 | 不恢复参数、不解绑、不新增按键禁用，不显示完成红灯 |
| 回调收尾任务投递失败 | 释放包装 pending，记录失败，留在 DUT |
| 默认参数恢复因忙被拒绝 | 不继续解绑或按键禁用 |
| 业务绑定写入/回读失败 | 不发布新的内存绑定状态，不继续按键禁用及完成灯提示 |
| 按键禁用写入/回读失败 | 不更新内存禁用状态，不显示完成红灯 |

上述失败会打印 `Finalpack FAILED; remain in DUT, no automatic poweroff`。这是“不再安排包装自动关机”的含义，不阻止物理断电、拨动电源开关或其他系统级关机。

流程不是可回滚事务：格式化可能已完成，部分参数可能已恢复，业务绑定可能已清除。VM 写入成功但回读失败时，掉电后的状态可能与本次内存状态不同；不能因失败就推断所有状态保持原样，也不要自动重发整包命令。

现有限制：

- 默认参数恢复中的部分底层接口没有完整的结果传播；成功提交日志证明格式化成功回调及两项关键 VM 校验通过，不代表所有参数逐项回读通过。
- 格式化库接口返回 `void`；若一直不回调，包装保持 pending，不自动宣告完成或关机，需要检查设备日志。
- 旧 BLE 回包不是完成确认；应观察完成红灯，再由测试人员拨码关机。
- 关键 VM 回读不能保证任意时刻掉电的全事务原子性。
- 目前没有覆盖整个 RDX 协议的包装事务锁；工站必须停止其他业务，不并发下发普通绑定、录音或存储指令。厂测入口的 pending 拦截不等同于全协议仲裁。

## 5. DUT 按键入口恢复

包装仅关闭物理按键进入 DUT 的入口，BLE `ft_dut` 入口保留。开机读取 `VM_RDX_KEY_DUT_DISABLED`：读到 `0xAA` 则禁止按键进入；其他情况沿用当前启用逻辑。正常重启不会主动清除禁用标记。

返工时：

1. 重新开机，通过 BLE 工厂 APP 连接。
2. 发送 `*APP#custom#ft_dut#1#`，等待进入 DUT。
3. 发送 `*APP#custom#ft_key_dut_enable#1#`。固件写入 `0xFF` 并回读校验，成功后恢复内存中的按键权限。
4. 退出 DUT 验证按键进入，再重启验证持久化状态。

仅通过 APP 进入 DUT 不会自动启用按键入口。写入/回读失败不更新内存状态，也不打印保存成功日志。再次成功执行包装结束会重新禁用入口。

“通过工厂 APP 开启”是现有操作方式，不表示该 APP 有独占权限；固件按协议命令处理。

- 忙状态拒绝、重复请求及重复回调。

该测试不模拟真实 SD、蓝牙控制器或掉电行为。实机至少验证：

1. 先绑定设备、保存测试录音，再执行包装结束。
2. 观察格式化成功回调和 `Finalpack committed`，确认红灯持续常亮、设备保持开机；验证蓝牙断连和充电事件不覆盖红灯，再拨码关机。
3. 重启确认广播 `bd = 0`、APP 重新读取为未绑定、测试文件消失。
4. 重启确认按键 DUT 被拦截，但 BLE 进入 DUT 和重新启用按键可用。
5. 验证蓝牙配对/HOGP 订阅清理及指定参数恢复。
6. 正常模式下 APP 设置非零自动关机时间后应读回相同值，重启后保留；在满足原有空闲条件（未充电、无连接、未录音等）时应按时关机。DUT 及包装期间等待超过该时间仍保持开机；成功后保持红灯，拨码 OFF 正常关机。正常 APP 恢复出厂设置应重启；包装不重启，后续 `ft_dut` 收尾命令应收到回包。
7. 失败注入时不得仅凭旧回包判定包装通过；对部分清理和 VM 状态不确定的设备安排返工检查。
